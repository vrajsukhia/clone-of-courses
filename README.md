# Atlas Learning Demo

A multi-page Next.js front-end that simulates a learning platform with course
catalog, progress tracking, and certificate download.

## Pages

- Home
- Courses
- Course Detail
- My Learning
- Certificate
- Login
- Profile

## Running locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the app.
